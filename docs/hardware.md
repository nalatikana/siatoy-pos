# อุปกรณ์หน้าร้าน

## เครื่องพิมพ์สติกเกอร์บาร์โค้ด

| หัวข้อ | ค่า |
|---|---|
| ยี่ห้อ / รุ่น | **EasyPrint ES-9960 Series** (แบรนด์ไทย ใช้ไดรเวอร์ตระกูล 4BARCODE / Seagull Scientific) |
| การเชื่อมต่อ | สาย USB เข้าโน้ตบุ๊กหน้าร้าน |
| ไดรเวอร์ | `4BARCODE_2024.2_M-3.exe` |
| ความละเอียด | **ยังไม่ยืนยัน** — ต้องอ่านจากไดรเวอร์ที่ลงแล้ว (ดูวิธีด้านล่าง) โดยทั่วไปเครื่องระดับนี้เป็น 203 dpi แต่บางรุ่นย่อยเป็น 300 dpi |
| ขนาดดวงที่ร้านใช้ | 30 × 20 มม. แบบม้วน |

### วิธีอ่านค่าความละเอียดจริง

Windows → การตั้งค่า → Bluetooth และอุปกรณ์ → เครื่องพิมพ์และสแกนเนอร์ → เลือก ES-9960 →
ค่ากำหนดลักษณะการพิมพ์ → แท็บ Options หรือ Graphics จะมีช่อง Resolution / Print Quality
บอกเป็น 203 dpi หรือ 300 dpi ตรง ๆ

ค่านี้จะถูกใส่ไว้ในหน้าตั้งค่าของระบบ แล้วตัวสร้างบาร์โค้ดจะปัดความกว้างแท่งให้ลงตัวกับจุดของเครื่องเอง
ทั้งสองค่า จึงไม่ต้องรีบหาคำตอบตอนนี้ก็ได้

### เลขความละเอียดมีผลยังไง

ที่ 203 dpi : 8 จุดต่อมิลลิเมตร → 1 จุด = 0.125 มม. → ดวง 30 × 20 มม. มีพื้นที่ 240 × 160 จุด
ที่ 300 dpi : ~11.8 จุดต่อมิลลิเมตร → 1 จุด ≈ 0.0847 มม. → ดวงเดียวกันมีพื้นที่ ~354 × 236 จุด

เครื่องพิมพ์เส้นที่บางกว่าหนึ่งจุดไม่ได้ ความกว้างแท่งบาร์โค้ดจึงต้องเป็นจำนวนจุดเต็ม ๆ เสมอ

กติกาที่ต้องยึดตอนวาดบาร์โค้ด :

1. **แท่งที่บางที่สุดต้องกว้างเป็นจำนวนจุดเต็ม ๆ** เช่น 2 จุด = 0.25 มม. หรือ 3 จุด = 0.375 มม.
   ถ้าออกแบบไว้ที่ 0.20 มม. เครื่องจะปัดให้เป็น 0.125 บ้าง 0.25 บ้าง แท่งจะกว้างไม่เท่ากัน
   เครื่องยิงอ่านพลาดง่ายขึ้นมาก
2. **แท่งบางที่สุดไม่ควรต่ำกว่า 2 จุด (0.25 มม.)** สำหรับงานหน้าร้านทั่วไป
3. เว้นขอบซ้ายขวาของบาร์โค้ด (quiet zone) อย่างน้อย 10 เท่าของความกว้างแท่งบางที่สุด

### เรื่องที่ต้องแก้ตอนทำหน้าพิมพ์บาร์โค้ด

โค้ดสร้างบาร์โค้ดในเดโมยืดภาพให้เต็มความกว้างดวงเสมอ (`preserveAspectRatio="none"` + `width:100%`)
แปลว่าความกว้างของแต่ละแท่งจะไปตกที่เศษของจุดแบบสุ่ม แล้วเครื่องพิมพ์ปัดเอาเอง
ตอนยกหน้านี้มาทำของจริง ต้องเปลี่ยนเป็น **กำหนดความกว้างเป็นมิลลิเมตรตามจำนวนโมดูลจริง**
(โมดูล × 0.25 มม.) แล้วจัดกึ่งกลางดวงแทน ไม่ยืดเต็มความกว้าง

มีไฟล์ `ทดสอบพิมพ์-สติกเกอร์-30x20mm.pdf` อยู่ในโฟลเดอร์โปรเจกต์แล้ว ใช้เทียบผลก่อน-หลังแก้ได้

### ตั้งค่าตอนพิมพ์จาก Chrome

- ในไดรเวอร์ : ตั้งขนาดกระดาษเป็น 30 × 20 มม. และเลือกชนิดสื่อให้ตรงกับสติกเกอร์ที่ใช้
  (ส่วนใหญ่เป็นแบบความร้อนตรง ไม่ต้องใช้ริบบอน)
- ในหน้าต่างพิมพ์ของ Chrome : Margins = **None** · Scale = **100** (ห้ามใช้ Fit to page) ·
  ปิด Headers and footers · เปิด Background graphics
- ตัวแอปสั่ง `@page{size:30mm 20mm;margin:0}` ให้อยู่แล้วตอนเลือกโหมดสติกเกอร์ม้วน

## เครื่องยิงบาร์โค้ด (USB)

ตั้งค่าให้เคาะ **Enter** ต่อท้ายรหัสอัตโนมัติ (suffix = CR) ไม่งั้นต้องกด Enter เองทุกครั้ง
วิธีตั้งคือยิงบาร์โค้ดคำสั่งในคู่มือที่แถมมากับเครื่อง

## iPad / มือถือ

ใช้กล้องสแกนแทนเครื่องยิง ยังไม่ได้ทำ อยู่ในเฟส 3

## เครื่องพิมพ์ใบเสร็จ 58 มม.

ยังไม่ได้ซื้อ ยังไม่ตัดสินใจว่าจะใช้หรือไม่

## ข้อจำกัดที่ต้องรู้ก่อนออกบูธ

เครื่องพิมพ์ต่อผ่าน USB เข้าโน้ตบุ๊กหน้าร้าน แปลว่า **iPad สั่งพิมพ์สติกเกอร์เองไม่ได้**
สติกเกอร์ทั้งหมดต้องพิมพ์ที่ร้านก่อนยกของไปงาน หรือยกโน้ตบุ๊กกับเครื่องพิมพ์ไปด้วย
เรื่องนี้ไม่กระทบการขายที่บูธ เพราะบูธแค่ยิงบาร์โค้ดที่แปะมาแล้ว
