# ต่อระบบเข้ากับ Supabase

ทำครั้งเดียวตอนเริ่มใช้งานจริง ใช้เวลาราว 15 นาที

## 1. สร้างโปรเจกต์

สมัคร supabase.com → New project → เลือกภูมิภาคที่ใกล้ไทยที่สุด (Singapore)
ตั้งรหัสผ่านฐานข้อมูลแล้วเก็บไว้ให้ดี

## 2. รันสคีมา

Supabase → SQL Editor → New query → วางเนื้อไฟล์ `db/001_schema.sql` ทั้งไฟล์ → Run

สคีมานี้ถูกทดสอบกับ PostgreSQL 16 จริง และทดสอบผ่าน PostgREST
(ตัวเดียวกับที่ Supabase ใช้เป็น REST API) มาแล้วทั้งเรื่องสิทธิ์และการส่งข้อมูลซ้ำ

## 3. สร้างผู้ใช้

Authentication → Users → Add user (ใส่อีเมลกับรหัสผ่าน ติ๊ก Auto Confirm User)
ทำทีละคนตามจำนวนพนักงาน แล้วคัดลอก User UID ของแต่ละคนมาใส่ในคำสั่งนี้ที่ SQL Editor

```sql
insert into profiles (id, display_name, role) values
  ('<UID ของเจ้าของ>',   'เสี่ยทอย',    'owner'),
  ('<UID ของหัวหน้า>',   'หัวหน้ากอล์ฟ', 'supervisor'),
  ('<UID ของพนักงาน A>', 'พนักงาน A',   'staff');
```

สิทธิ์มีสามระดับเท่านั้น : `staff` `supervisor` `owner`
ระดับนี้บังคับที่ฐานข้อมูล ไม่ใช่แค่ซ่อนปุ่ม — พนักงานจะ **ไม่ได้รับข้อมูลต้นทุนมาที่เครื่องเลย**

## 4. สร้างจุดขาย

```sql
insert into locations (code, name, kind) values
  ('SHOP', 'หน้าร้าน', 'shop');
```

บูธงานเพิ่มทีหลังได้จากหน้าตั้งค่าระบบในแอป

## 5. ใส่คีย์ลงในแอป

Supabase → Project Settings → API → คัดลอก **Project URL** กับ **anon public key**
มาใส่ใน `src/config.js`

```js
supabaseUrl:     'https://xxxxxxxx.supabase.co',
supabaseAnonKey: 'eyJhbGci...',
```

anon key ถูกออกแบบมาให้เปิดเผยได้ ทุกเบราว์เซอร์ที่เปิดแอปก็เห็นอยู่แล้ว
ความปลอดภัยอยู่ที่การล็อกอินและกฎสิทธิ์ในฐานข้อมูล

> **ห้ามเอา `service_role` key มาใส่เด็ดขาด** คีย์นั้นข้ามกฎสิทธิ์ทั้งหมด
> ใครได้ไปก็อ่านและแก้ข้อมูลทั้งฐานได้ ถ้าเผลอใส่แล้ว push ขึ้น repo ที่เป็น public
> ต้องเข้าไป revoke ที่ Supabase ทันที

## 6. ใส่ข้อมูลตั้งต้น

หลังนับสต๊อกวันตัดยอดแล้ว ใส่สินค้าและยอดยกมา ผ่านหน้า **สินค้า & สต๊อก** ในแอปได้เลย
หรือถ้ามีเป็นไฟล์ ส่งไฟล์มาให้ผมแปลงเป็นคำสั่ง SQL ให้

ยอดยกมาต้องลงเป็น `move_type = 'opening'` เสมอ ห้ามแก้ยอดคงเหลือตรง ๆ
เพราะระบบไม่มีช่องคงเหลือให้แก้ ทุกยอดคำนวณจากสมุดเดินของ

## สิ่งที่เกิดขึ้นตอนแอปเจอคีย์ครั้งแรก

1. ขึ้นหน้าล็อกอินแทนการเข้าหน้าขายเลย
2. ล็อกอินสำเร็จ → ล้างข้อมูลตัวอย่างในเครื่องทิ้ง แล้วดึงของจริงจากเซิร์ฟเวอร์
3. สิทธิ์มาจากบัญชี ปุ่มสลับสิทธิ์ที่มุมขวาบนหายไป
4. บิลที่ขายจะลงเครื่องก่อนเสมอ แล้วส่งขึ้นเซิร์ฟเวอร์เบื้องหลังทุก 20 วินาที
   และทันทีที่เน็ตกลับมา

## ที่ยังไม่ได้ทำ

- **ส่งสรุปยอดตอนตี 1 อัตโนมัติ** ต้องทำเป็น Edge Function + ตารางเวลาฝั่ง Supabase
  หน้าเว็บทำเองไม่ได้เพราะตอนนั้นไม่มีใครเปิดแอปค้างไว้
- **PIN สลับคนหน้าเครื่องเดียวกัน** ช่อง `pin_hash` เตรียมไว้ในตารางแล้ว ยังไม่ได้ทำหน้าจอ
- **แนบสลิปโอน** ต้องเปิด Storage bucket ก่อน
